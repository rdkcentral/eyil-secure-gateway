# Specification source map

The agreed contracts are canonical in the capability specs below. This map covers
all **167 source ranges in seven files (8,165 original lines)**. Original line ranges
identify the migration snapshot, not current line numbers; use the heading links
to navigate after extraction. Every range has been reviewed.

The guides retain the original ACs, diagrams, rationale, examples, operational
instructions and verification evidence. Requirement links replace migrated prose.
Detailed contract clauses/tables are normative parts of their OpenSpec requirements;
scenarios illustrate them without discarding exceptions. Explicit proposed/future
labels retain their status. This is documentation traceability, not runtime test evidence.

The unchanged original ACs remain in [sections 2.1–2.3](EyilSecureGateway.md#2-acceptance-criteria-and-scope).
The six unresolved decision IDs remain in [sections 7.1–7.2](EyilSecureGateway.md#71-abnormal-backend-completion-lifecycle-integration-boundary);
integration checks in section 7.3 and settled scope notes in 7.4 are separate.
The [libzmq patch](zmq_connection_lifetime.patch) remains unchanged.
